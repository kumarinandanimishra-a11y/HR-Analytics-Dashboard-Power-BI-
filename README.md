# HR-Analytics-Dashboard(Power-BI)
📌 Project Overview

Developed an Interactive HR Analytics Dashboard in Power BI to analyze workforce data for a 500-employee organization.Cleaned raw HR data with power Query and created KPIs for Attrition Rate, Average Age, Average Tenure, and Employee count. visualizations explored attrition by department, gender distribution by job level, salary breakdown, performance vs tenure, and training impact on performance. The project showcases end-to-end data analysis skills-- from data cleaning to delivering insights that help HR teams improve retention,training, and compensation startegies.

 🛠️Tool Used
 | Tool / Skill            | How It Was Used                                                          |
| ----------------------- | ------------------------------------------------------------------------ |
| **Power BI Desktop**    | Dashboard design & interactive reporting                                 |
| **Power Query (ETL)**   | Data cleaning, type conversion, column standardization                   |
| **DAX**                 | Custom measures (Attrition Rate %, Avg Tenure, Avg Age)                  |
| **Data Modeling**       | Relationships & star-schema structure                                    |
| **Data Storytelling**   | KPI-first layout with drill-down visuals                                 |
| **Analytical Thinking** | Correlation analysis (training vs performance, absences vs satisfaction) |

💡 Key Insights Discovered
1. Attrition is concentrated in Engineering & Sales
2. Senior level has the largest salary share
3. Training hours show no consistent uplift in performance scores
4. Higher absence counts correlate with lower satisfaction scores
5. Senior roles have the highest headcount
